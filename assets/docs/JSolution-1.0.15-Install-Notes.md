# JSolution 1.0.15 설치 화면 안내

작성일: 2026-10-16

## 포함 제품

| 제품 | 버전 | 형식 |
|---|---|---|
| 솔루션 진단기 | 1.0.15 | 필수 MSI |
| JCore | 1.1.0 | 원본 MSI |
| JView | 1.1.3 | 원본 MSI |
| PLC Simulator | 1.0.71 | 원본 EXE |

JSolution_Setup.exe 하나로 배포합니다. 진단기만 설치하는 최소 구성, .NET Framework 4.8 오프라인 파일, 제품별 독립 설치 및 기존 운영 진단 설정을 유지합니다.

## 화면 흐름

1. **소프트웨어 이용 동의**: 오프라인 이용 조건을 읽고 체크해야 다음 단계로 이동합니다. 기본 체크는 해제입니다.
2. **설치할 제품 선택**: 설치할 제품과 탐지된 기존 버전을 확인합니다. 진단기는 필수이며 선택 제품의 체크 해제는 기존 제품 제거를 의미하지 않습니다. 이전 버튼으로 이용 동의 화면에 돌아갈 수 있습니다.
3. **설치 진행**: 제품 선택 화면과 분리한 진행 화면에서 설치 요약, 전체 상세, 제품별 로그와 시스템 진단 탭을 제공합니다. 취소 후에는 안전한 종료와 롤백을 기다립니다.
4. **결과 확인**: 제품별 설치 완료, 업데이트 완료, 동일 버전 유지, 선택하지 않음, 실행하지 않음 등을 표시합니다. 실제 실행 결과와 작업 후 MSI 등록 버전을 대조합니다. 성공 코드만 받았어도 설치 등록을 확인하지 못하면 결과 확인 필요로 표시합니다.

오류가 발생하면 **오류 처리 중** 화면에 로그를 표시하고, 종료 또는 롤백이 끝나면 **설치를 완료하지 못했습니다** 화면에 제품별 결과를 표시합니다. 사용자 취소는 별도의 취소 화면입니다. MSI 오류에 대한 설치기의 취소 응답을 사용자가 직접 취소한 것으로 오표시하지 않습니다. 다른 제품에서 오류가 나더라도 실제 설치된 독립 제품의 확인된 결과는 구분해 표시합니다.

완료 화면의 예:

```text
JCore            설치 완료
JView            업데이트 완료
PLC Simulator    동일 버전 유지
```

위 문구는 화면 예시입니다. 실제 결과는 설치 대상 PC에서 확인한 실행·버전·롤백 상태에 따라 달라집니다.

## 로그 저장

설치 진행·오류·취소·완료 화면에서 **로그 저장**을 사용할 수 있습니다. 완료 화면에서는 **상세 로그 보기**로 기존 탭을 펼칩니다. 저장 파일에는 제품별 결과와 화면에 표시된 로그를 통합합니다. 개별 상세 파일은 최근 512KB까지 포함하며 전체 원본은 **로그 폴더**에서 확인합니다. 서비스 로그·Windows 이벤트 수집이 진행 중이라면 수집 완료 후 다시 저장하면 최신 자료가 포함됩니다. 비밀번호·토큰 등 기존 숨김 처리를 유지합니다.

## 이용 조건 문안

이용 조건 원문은 `installer/License.ko.txt`에 있으며 설치 파일과 진단기 설치 폴더에도 포함합니다. JAYONSTUDIO 제품용 기본 문안으로 작성했으며 공정거래위원회 인증 표준약관으로 표시하지 않습니다. 제품별 이용허락·평가 조건·별도 계약이 우선하고, 이 동의가 유료 기능을 부여하거나 개인정보 수집 동의를 대신하지 않습니다. 제3자 구성요소에는 각 권리자의 조건이 적용됩니다.

법률상 허용되는 백업·호환 목적 역분석 등의 권리를 일괄 제한하지 않도록 작성했습니다. 관련 참고: [저작권법 제101조의4](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=04&joNo=0101&lsiSeq=283335&urlMode=lsScJoRltInfoR). 사업별 라이선스·지원·상업 조건이 확정되면 해당 문안을 기준으로 조정할 수 있습니다.

## 무인 설치 변경

이용 조건을 검토하고 동의한 배포 담당자는 다음과 같이 명시적으로 전달합니다.

```powershell
.\JSolution_Setup.exe /quiet /norestart AcceptLicense=1
```

동의 인수 없는 /quiet 또는 /passive 설치·복구는 Plan/Apply 전에 차단하고 종료 코드 1603을 반환합니다. 일반 화면의 동의 체크는 실제 적용 직전에도 확인합니다. 제거 작업에는 새로운 이용 동의를 요구하지 않으므로 기존 제품 제거와 관련 번들 정리는 계속 가능합니다. /help는 설치 없이 종료합니다.

## 검증 범위

원본 패키지 SHA256 및 번들 추출 동일성, 기존 설치 정책·로그·호출 검사, 동의·결과·오류·취소·롤백 분류 28개, WPF 단계 전환·로그 저장 콜백·화면 렌더링 14개를 검증합니다. 오류 화면은 최소 크기 1020×760에서도 확인합니다. 화면 테스트는 합성 제품 상태를 사용하며 실제 설치를 수행하지 않습니다. 동의 없는 실제 무인 EXE 실행이 Plan/Apply 전에 차단되는지와 도움말 실행을 별도로 확인합니다.

새 제품 버전의 실제 PC 설치·서비스 시작·업그레이드·롤백·재부팅은 환경별 추가 검증이 필요합니다.

## 설치 파일 저장 위치

최종 EXE와 SHA256 파일은 빌드 시 InstallPackage\JSolution 폴더에 저장합니다. 내부 검증 자료는 artifacts\installer\1.0.15에 유지합니다. 같은 버전 재빌드에서 왼쪽 CI 하단 문구를 로고와 같은 폭으로 가운데 정렬했습니다.
