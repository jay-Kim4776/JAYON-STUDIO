# JSolution 1.0.17 설치 안내

작성일: 2026-10-18

## 포함 제품

| 제품 | 버전 | 형식 |
|---|---|---|
| 솔루션 진단기 | 1.0.17 | 필수 MSI |
| JCore | 1.1.1 | 원본 MSI |
| JView | 1.1.3 | 원본 MSI |
| PLC Simulator | 1.0.71 | 원본 EXE |

최신 JCore 1.1.1 설치파일을 포함했습니다. JSolution_Setup.exe 하나로 배포하며 .NET Framework 4.8 오프라인 파일을 포함합니다.

## 설치 방법

관리자 권한으로 실행하고 이용 동의 → 제품 선택 → 설치 진행 → 제품별 결과 순서로 진행합니다. 진단기만 설치하는 최소 구성이 가능합니다. 기존 제품을 선택 해제해도 삭제하지 않으며 같은 버전은 유지하고 하위 버전 설치는 차단합니다.

오류 시 설치 로그를 저장하세요. 실제 대상 PC의 설치·서비스 시작·업데이트는 환경별 확인이 필요합니다.

## 아이콘 및 진단

선택한 파란색 S 심볼을 바로가기·런처·설치파일·진단 웹 탭에 유지합니다. 대시보드 기본 포트는 5088입니다. 기존 설정·데이터·로그를 보존합니다. 제품의 진단 API 주소와 보호 키 경로는 실제 실행 환경과 일치해야 합니다.
