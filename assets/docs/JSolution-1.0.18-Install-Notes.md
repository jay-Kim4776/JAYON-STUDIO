# JSolution 1.0.18 설치 안내

작성일: 2026-10-18

포함 제품: 솔루션 진단기 1.0.18, JCore 1.1.1 재배포 MSI, JView 1.1.3 MSI, PLC Simulator 1.0.71 EXE.

FieldScope 1.5.5 Android APK는 Windows 통합 설치기가 설치하지 않으며 별도 제공합니다. 전체 설치파일 ZIP에는 JSolution_Setup.exe, PLCSimulator_Setup.exe, FieldScope-1.5.5.apk 및 각 SHA256을 담았습니다.

관리자 권한으로 통합 설치파일을 실행하세요. 이용 동의 → 제품 선택 → 설치 진행 → 결과 순서이며 진단기만 설치하는 최소 구성을 지원합니다. 기존 제품은 선택 해제해도 제거되지 않습니다. 오류 시 로그를 저장할 수 있습니다.

## JCore 동일 버전 재배포 주의

이번 JCore 1.1.1 MSI의 SHA256은 9DB83FAE322357B5C9FC353EF21B1CC746A67EA1FCB875F18FD8F5716C89C243입니다. 이전 1.1.1과 내용은 다르지만 제품 버전은 같습니다. 기존 1.1.1 설치 PC에서는 통합 설치기의 동일 버전 유지 정책에 따라 JCore를 자동 교체하지 않습니다. 해당 PC 업데이트는 JCore 측에서 버전을 올린 MSI를 제공받거나 제품의 동일 버전 재설치 절차를 확인해야 합니다. 신규 설치 및 이전 버전에서의 업데이트에는 이번 MSI가 포함됩니다.

FieldScope 설치본은 1.5.5, 제공 소개서와 사용자 매뉴얼은 1.5.4입니다. 실제 대상 PC·Android 설치와 서비스·PLC 연결 시험은 수행하지 않았습니다.

최종 설치파일 저장 위치: InstallPackage\JSolution
