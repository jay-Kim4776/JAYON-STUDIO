# JSolution 1.1.4 설치 안내

작성일: 2026-10-22

PLC Simulator 1.0.77 제공 설치파일을 그대로 포함했습니다.

| 제품 | 설치 패키지 버전 |
|---|---|
| JSolution | 1.1.4 |
| JCore | 1.1.4 |
| JView | 1.2.4 |
| PLC Simulator | 1.0.77 |
| FieldScope | 1.5.7 (별도 Android APK) |

진단기만 설치하는 최소 구성, 단계별 설치와 로그 저장 및 바로가기 모음을 유지합니다.
전체 ZIP에는 통합 설치 EXE, Simulator 단독 설치 EXE와 FieldScope APK를 포함합니다.
사용자 요청에 따라 추가 설치파일 검증과 설치 시험은 수행하지 않았습니다.
