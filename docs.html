C# 스크립트는 어떻게 사용하나요?

프로젝트 트리의 Scripts → + 스크립트 추가에서 시작합니다. 초기화 로직, 실행 주기와 개별 활성화를 설정하고 변경안을 저장하면 실행에 적용됩니다. 주기를 0으로 설정하면 자동 주기 실행 없이 수동 호출로 사용할 수 있습니다.

Admin과 User는 코드를 편집·실행할 수 있으며 Guest는 접근할 수 없습니다. PLC 쓰기는 프로젝트의 공통 허용 설정과 태그 쓰기 권한을 따릅니다. DB 연계는 OLE DB 공급자와 연결 설정을 별도로 준비합니다.

설치 방법 및 MSI 수동 설치

JCore-Setup.exe를 더블클릭하고 Windows 권한 요청에서 예를 선택하세요. 기존 MSI 설치 화면으로 연결됩니다. MSI 파일로 직접 설치할 경우 아래 방법을 사용하세요.

  1. 시작 메뉴에서 cmd를 검색합니다.
  2. 명령 프롬프트를 우클릭해 관리자 권한으로 실행을 선택합니다.
  3. 아래 명령의 파일 경로를 실제 다운로드 경로로 바꿔 실행합니다.
msiexec /i "C:\Downloads\JCore.msi" /L*V "%TEMP%\JCore-install.log"

실제 파일명은 다운로드한 버전에 따라 다릅니다. 설치 완료 후 services.msc에서 JCore를 확인하세요. 업데이트 전 설정과 라이선스를 백업하세요.
