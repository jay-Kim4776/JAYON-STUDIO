Android 10 이상 · Version 1.5.4 · PLC에 연결 가능한 네트워크 필요

FROM CONNECTION TO INSPECTION

설비별 연결 정보를 보관하고,
필요한 태그를 빠르게 확인합니다.

프로젝트와 디바이스

설비별 프로젝트 안에 PLC 디바이스를 등록합니다. 드라이버·IP·포트와 타임아웃·재접속 옵션을 화면에서 설정합니다.

태그와 현재 값

이름·주소·그룹 경로로 태그를 찾고, 그룹 드롭다운으로 목록을 좁혀 값과 품질을 확인합니다. 수집을 시작·정지하거나, 정지 상태에서 한 번 읽을 수 있습니다.

CSV로 설정 관리

프로젝트를 CSV 한 파일로 내보내고 Excel에서 편집합니다. 가져오기 전 변경 내용을 확인하고 검증 후 프로젝트 전체를 교체합니다.

CSV에 없는 디바이스·태그는 전체 교체 시 삭제됩니다. 형식 오류나 라이선스 한도 초과 시 교체를 적용하지 않습니다.

SUPPORTED ETHERNET DRIVERS

PLC와 직접 연결하는 모바일 점검.

드라이버기본 포트주소 예시 / 지원 범위
MELSEC Q MC 3E5000D0 · M0 · X0 · Y0 / 3E Binary
LS XGI2004%MX0 · %MW0 · %MD0 / M 메모리 영역
Modbus TCP502C:0 · DI:0 · HR:0 · IR:0 / 비트·레지스터

BOOL, 16·32비트 정수, FLOAT32를 지원합니다. PLC의 통신 설정과 주소 범위를 확인하세요. CPU USB 직접 통신과 STRING은 소개서 1.5.4 기준 지원하지 않습니다.
