DATA FOUNDATION

통신부터 응용 프로그램까지.

PLC 통신과 재연결

MELSEC·LS XGT 등 현장 PLC를 통신 드라이버로 연결합니다. 런타임이 데이터를 수집하고 통신 장애 시 재연결을 처리합니다.

태그 서비스

값(Value), 품질(Quality), 시간(Timestamp)을 관리하고 태그 변경을 구독해 응용 프로그램에 반영합니다.

API / OPC UA 연동

JCore API와 클라이언트 라이브러리로 조회·쓰기를 개발합니다. OPC UA 인터페이스로 상위 시스템과 연결합니다.

APPLICATIONS

현장 데이터를 필요한 곳으로.

공정 데이터 수집

여러 PLC의 데이터를 공통 태그로 구성해 설비별 값을 관리합니다.

맞춤형 시스템 개발

API를 활용해 필요한 모니터링 프로그램과 데이터 처리 로직을 구현합니다.

상위 시스템 연계

MES·SCADA 등 상위 응용 프로그램과 현장 데이터를 연결합니다.
