01 / CONNECTIVITY

Multi PLC Connectivity

Mitsubishi, LS Electric, Rockwell, Modbus 장비를 드라이버별 통신 설정으로 연결합니다.

02 / TAG ENGINE

Unified Tag Management

Device·Memory·System 태그를 프로젝트와 그룹 단위로 구성하고 관리합니다.

03 / INTEROPERABILITY

OPC UA & Client SDK

표준 OPC UA와 .NET 클라이언트 API로 태그 값을 읽고 씁니다. 기능별 라이선스를 지원합니다.

04 / OPERATIONS

Web Management

웹에서 장비와 태그를 설정하고, 실시간 값·통신 상태·로그를 확인합니다.

05 / ACCESS CONTROL

Unified Authentication

웹·OPC UA·SDK에서 계정을 공통 사용합니다. Admin/User 역할과 게스트 조회 권한을 구분합니다.

06 / SCRIPTING

C# Scripting

프로젝트별 C# 클래스로 태그 읽기·쓰기와 계산 로직을 구성합니다. 주기 실행과 수동 호출, 같은 프로젝트의 스크립트 간 함수 호출을 지원합니다.

FROM DATA TO ACTION

익숙한 C#으로, 현장에 맞는 로직을.

태그 값을 읽어 계산하고, 결과를 Memory 태그에 저장하거나 허용된 PLC 태그에 반영하세요. 웹 편집기에서 코드를 수정하고 실행 로그와 오류 위치를 확인할 수 있습니다.

지원 PLC / Protocol

현재 구현 기준
드라이버와 현재 지원 범위
제조사 / 프로토콜지원 범위상태
MitsubishiMELSEC Q · MC 3E Binary / ASCII · TCP구현됨
LS ElectricXGT · XGI/K · TCP구현됨
Rockwell AutomationControlLogix · EtherNet/IP · Symbolic Tag구현됨
ModbusMaster · TCP / RTU구현됨
SiemensS7개발 예정

지원 범위는 PLC 모델·설정에 따라 다릅니다. Modbus RTU는 구현되어 있으나 실제 시리얼 PLC 현장 검증은 필요합니다. ControlLogix UDT는 지원 범위를 매뉴얼에서 확인하세요.
